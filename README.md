
# Smart Encryption Tool

Smart Encryption Tool is a C++-based application developed to securely encrypt and decrypt files using a password-based XOR encryption technique. The project follows a modular design with separate components for encryption, password management, history tracking, and utility functions. It includes features such as file encryption and decryption, password strength analysis, operation history logging, file size display, progress indication, and error handling. The project demonstrates Object-Oriented Programming (OOP), file handling, STL usage, and modular software design principles.
